## 年付入门款的资源够不够用？

20G KVM 的关键参数是 1GB 内存、20GB 存储和每月 1TB 流量。判断够不够，最好从自己的应用倒推：

- **轻量测试、个人小项目或资源占用较低的服务**：可以先核对软件最低资源要求，再考虑入门档。
